# BC Elite QC

BC Elite QC is a hardware auditing, diagnostics, and quality control software suite developed by Bizz Co Hub LLC.

## Features
- **System Health Diagnostics**: Automated checking for CPU, RAM, SSD, Graphics, and Battery parameters.
- **Detailed Component Audit**: High-fidelity details for RAM configuration, SSD wear level percentages, GPU adapters, and charge cycle counts.
- **Auto-Updater**: Seamless checking and installation of updates directly from the GitHub releases channel.
